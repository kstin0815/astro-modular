通順，是最重要的。因為倘若不通順，那麼不說認同與否，讀者甚至無法理解你要說什麼。而既然無法理解，那麼就算有人剛好和贊同了你，他也不是真的被你說服，而只是看到關鍵字就高潮罷了。通順，又分兩部分：通和順。

▌通，是邏輯說得通；順，是文章讀得順。

在「通」的部分，我們要「軟硬兼施」：不只要有邏輯，也要有修辭。但不同於三段論和條件句等嚴格的邏輯推論規則（三段論是集合的蘊涵關係，而命題邏輯則是條件關係）在日常交流時我們只需要簡單的「Ａ→Ｂ→好」結構。

▌具體來說：「為什麼Ａ是好的？」

因為「Ａ會造成Ｂ」且「Ｂ是好的」，前者稱為連結（link）後者稱為影響（impact）——在辯論中，思考或檢驗何種 link 和 impact 成立或不成立又有沒有其他可能，是基礎中的基礎。而除了反駁 link 和 impact 不成立之外，更強而有力的作法是反轉（turn）：對立成因或辯證思考。

這個推論模型，相較於三段論和條件句好在兩個地方：一是，從 link 到 impact 的「Ａ→Ｂ→好」是順序的思考，而不像不管是三段論還是條件句，如果想要論證「Ａ是好的」都必須先將它作為結論再反推「是什麼前提為真導致了Ａ是好的這一結果？」又或者是「有什麼都是好的而且包含了所有的Ａ？」光是重建論證就已經極費腦力，整個思考順序還非常反直覺。二是，「Ａ→Ｂ→好」可以很簡單的標誌出誰是論點的核心：也就是Ｂ，以便切割和詮釋。

▌以及「在多個Ｂ之間」排列組合。

最常見的是並列、遞進、轉折。將符合MECE原則的論點加以並列或遞進，或將並列轉折以形成對比，或以因果轉折舉輕以明重和預設反駁。例如：「通順，是最重要的。因為倘若不通順，那麼不說認同與否，讀者甚至無法理解你要說什麼。而既然無法理解，那麼就算有人剛好和贊同了你，他也不是真的被你說服，而只是看到關鍵字就高潮罷了。」在這句話中，通順才能認同，不通順甚至無法理解；無法理解就不是真的被說服。這些種種，都是沒有被例證支持的觀點，但是藉由修辭手法（舉輕明重：就算…，更何況…／預設反駁：除非…，但即便…）這句話依舊可以帶來足夠的說服效果，而讓人覺得：「它的邏輯好像說得通！」

--

在「順」的部分，我們要銜接（cohesion）和連貫（coherence），以拼圖來為喻，銜接是兩塊拼圖能緊密嵌合連結在一起，連貫是整幅拼圖拼完之後，所形成的圖案能是有意義的畫面。

具體來說，我們有段落之內的句子和句子之間的銜接和連貫，以及段落和段落之間的銜接和連貫。句子和句子之間的銜接，大致有三種方式：重複相同內容、有邏輯的排列、自問自答與懸念。⑴重複相同內容，又稱為以舊引新，是指段落之內連續或不連續的句子都是以相同主語開始，或者每一個新的句子都是以前一句已經出現的內容為開頭，然後帶出新內容，再被後一句重複。⑵有邏輯的排列。例如論證模型的 link 和 impact，多個Ｂ之間的並列遞進轉折包含舉輕明重和預設反駁，論證和例證。⑶自問自答與懸念。除了重複內容和有邏輯聯繫之外，另一個比較難以歸類的技巧，是在寫作時站在讀者立場設身處地的提出問題。有時候是明顯的自問自答，有時候是只把問題當作自我提示詞，然後直接補完讀者可能有興趣或感到困惑的問題的回答。甚至還有的時候，是故意在句子結尾留下懸念，等到下一句才解答。

至於，句子和句子之間的連貫，只要確保每一個句子都是圍繞著段落的主旨展開即可。換句話說，也就是金字塔原理的橫向和縱向關係。

段落和段落之間銜接與連貫大體也是如此。我們可以不看其他內容，只看每個段落的要點和主題句，看看這些要點或主題句與其他要點或主題句之間有沒有圍繞文章主題展開：因為我們其實可以把整篇文章中的每一個段落都壓縮成一句話，而讓整篇文章成為一個段落；或反過來把段落中的每個句子單獨拎出來作為新的主題句寫成各自完整的段落成為一篇新文章。

--

但段落之間的連貫還涉及「引人入勝」。

引人入勝，也分兩部分：意外和共鳴。意外有說理敘事內的意外和敘事外的，但其實都同屬表達形式的修辭技巧：因為除了極少數真正的新思想外，大多數的意外都只來自出其不意。共鳴來自內容，有形式也有實體，但真誠的理解難得，我們只能在盡可能準備形式的詩意。

⑴說理敘事內的意外，例如猜想落空和歸謬反證和舉輕明重和預設反駁一樣同屬「轉折」的修辭技巧；或往前鋪墊製造錯誤預期，以對比巧妙提問將答案包裝成問題。⑵敘事外的意外試圖產生新思想，常見的方法有兩種：第一種即是 link 和 impact 的反轉。前者思考有無作為背景而被忽略的因果或甚至倒果為因，或改變描述關係或狀態的詞語；後者切換情境和角色或立場，或找出影響判斷的隱藏前提和更往前挖掘需求找出反轉利弊的辯證點。或更字面意義的修辭的，改變框架和詞與和隱喻和類比。

第二種是類比和切分：⑴同屬相同範疇的並列關係、⑵擁有共同變量的遞進關係、⑶有共性但也有變量的轉折遞進關係、⑷繪製出共性和變量的矩陣關係或直接建立系統，然後操作個別條件的有無定位每個概念位置或構成使討論成立的前提——從範疇內性質的切分，再到不同面向或甚至前提要件的切分，然後跨範疇的連結即是類比，而也是在思考 link 和 impact 的其他可能，因為辯論本就是：「在眾多可能的連結和影響的討論標的之中，選出諸多可能之中你覺得更重要，但被人們忽略的那一個。」

最後要有共鳴，給予命名或比喻，然後放置到具體場景之中給出細節：不要抽象而要具體，感官可見的 concrete，不寬泛不含糊的 specific 和 particular，不只是理論概念的 actionable——具體的行為，或就是可觀察的操作性定義。最好是高度衝突與性和暴力有關並要付出極高代價，或打破第四面牆的詩意想像或抉擇場景。
